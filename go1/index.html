How it works

  1. Enter GitHub owner, repository and token.
  2. Enter a Slug such as go1 and destination URL.
  3. Click Create / Update.
  4. The system creates go1.html directly inside your GitHub repository.
  5. Your live URL becomes go1.html — no ?id=.
