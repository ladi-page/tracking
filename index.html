This GitHub-only version stores changes in this browser. For a global change visible to every visitor, edit config.js and push the change to GitHub.

How it works

  1. Set your destination in config.js.
  2. Upload all files to a GitHub repository.
  3. Enable GitHub Pages.
  4. Use /go.html as your permanent redirect URL.
